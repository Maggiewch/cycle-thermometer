# 周期温度计

用穆雷·罗斯巴德《美国大萧条》中的奥地利学派周期框架（信贷扩张 → 不当投资 → 拐点 → 萧条），以同一套指标和同一条判断规则，研究**美国、英国、日本、中国**当前所处的经济周期阶段，并与 1929—1933 年对照。

在线查看：<https://maggiewch.github.io/cycle-thermometer/>

## 2026 年 11 月的读数

| 国家 | 阶段 | 周期温度 |
|---|---|---|
| 美国 | 繁荣后期 | 44° |
| 中国 | 收缩 | 43° |
| 日本 | 拐点 | 39° |
| 英国 | 收紧中 | 23° |

温度衡量偏离常态的程度，方向要看热度落在哪个阶段。详见 [方法说明](docs/02-method.md)。

## 本地打开

直接双击 `index.html` 即可（数据已打包在 `assets/data.js` 里）。也可以启动一个本地服务器：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 更新数据

1. 修改 `data/` 下对应的 JSON 文件（数值、日期、来源）。
2. 重新打包：

```bash
python3 scripts/build_data.py
```

状态、阶段判断和周期温度都由页面根据数据自动计算。`data/country_view.json` 里的文字解读需要手动改写。

## 说明与局限

- 数据是 2026 年 11 月 25 日抓取的快照，不会自动更新。
- 美国数据来自 FRED；英国、日本、中国来自 OECD 和 BIS（经 FRED）以及媒体转述的官方数据；部分市场数据来自网站和研究报告，各家数字有出入。
- 警惕线和危险线是经验阈值，不是预测模型。各国指标数量不同，按项数计的阶段规则对指标多的国家更敏感，详见方法说明。
- 本仓库不包含《美国大萧条》原文；读书笔记为概括，书的版权归原作者和出版方所有。
- 这是经济分析框架，**不构成投资建议**。
