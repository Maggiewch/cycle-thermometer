# 方法：指标、阈值、阶段判断与周期温度

数据抓取日期：2026 年 11 月 25 日。

## 一、五个部分

每个国家的指标都按罗斯巴德周期分成五个部分：

| 部分 | 问的问题 | 例子 |
|---|---|---|
| 1. 信贷扩张 | 繁荣的燃料足不足 | 广义货币增速、企业贷款增速、实际政策利率、私人信贷占 GDP 一年变化 |
| 2. 不当投资 | 泡沫在哪里、债务有多重 | 私人信贷占 GDP、房价、估值、杠杆、资本开支 |
| 3. 拐点信号 | 信贷扩张是否在停止 | 政策利率变化、长端利率、股市回撤、信用利差、银行放贷标准 |
| 4. 实体经济 | 衰退是否开始 | GDP、失业率及其变化、PMI、OECD 领先指标 |
| 5. 通胀（背景） | 物价逼不逼央行收紧，或是否在通缩 | CPI、PPI |

## 二、每项指标的状态

每项指标有警惕线和危险线，规则有三种：
- **≥**：数值越高越值得担心
- **≤**：数值越低越值得担心
- **偏离**：离常态太远都值得担心。房价以 2% 为常态，CPI 以 2% 为目标。

越过警惕线为“警惕”，越过危险线为“危险”。阈值是参考历史经验设定的经验值，不是预测模型。全部阈值写在 `data/*.json` 的 `warnAt`、`badAt` 字段里。

## 三、阶段判断（四国同一条规则）

核心触发器是每个国家都有的 5 项：股市较一年内高点、10 年期国债收益率一年变化、失业率一年变化、制造业 PMI、OECD 领先指标。

按顺序判断：
1. 核心触发器 3 项以上越过触发线，或实体经济组 2 项以上危险：**收缩**
2. 核心触发器 1 项以上越过，或拐点组 2 项以上危险：**拐点**
3. 信贷扩张组 3 项以上亮灯：**繁荣后期**
4. 拐点组 3 项以上亮灯：**收紧中**
5. 其余：**平稳**

美国另有 4 项专用触发器（企业贷款近 3 个月年化、高收益债利差、萨姆规则、首次申领失业金），只显示，不计入阶段判断。

**已知的局限**：各国指标数量不同（美国 34、英国 15、日本 17、中国 19），而上面的规则按“项数”计，所以指标多的国家更容易越过门槛。例如英国和日本的信贷扩张组只有 2 项，不可能被判为“繁荣后期”。比较国家时，核心触发器和共同指标对比表更公平。

## 四、周期温度（0—100°）

- 每项指标：正常 0°，警惕 50°，危险 100°
- 阶段温度：该阶段内所有指标的平均
- 国家温度：五个阶段等权平均，所以指标数量不同不影响总温度
- 25° 以下正常，25—50° 偏高，50° 以上为高

温度衡量的是偏离常态的程度，不区分方向。要看热度落在哪个阶段：信贷扩张和不当投资偏热是繁荣，拐点和实体经济偏热是收缩。

## 六、数据来源

- 美国：圣路易斯联储 FRED
- 英国、日本、中国：OECD 与 BIS（经 FRED），以及媒体转述的官方数据（英格兰银行、日本银行、中国人民银行、国家统计局等）
- 1928—1934 年：FRED 收录的 NBER 宏观历史数据库
- CAPE、融资余额、PMI 等来自网站或研究报告，各家数字有出入

每个数字的具体来源和网址写在对应 JSON 文件的 `source`、`url` 字段里。中国的 M2、新增贷款、PMI、CPI、PPI 来自媒体转述，未直接核对官方原始发布。
